# One Verse User Journeys

## Journey 01 — 오늘의 말씀 읽기와 완료

**목표:** 허용된 Day의 4트랙을 읽고 완료 기록을 남긴다.  
**진입점:** 홈의 읽기 CTA, 하단 말씀 뷰어 탭.  
**완료 조건:** One Verse가 있는 상태에서 완료 확인을 통과한다.

```mermaid
flowchart TD
  A[홈 또는 말씀 뷰어] --> B[읽기 데이터 로딩]
  B -->|실패| E[오류 Toast]
  B -->|성공| C[현재 허용 Day의 본문]
  C --> D[Day 선택 또는 이전/다음 이동]
  D --> F{허용된 Day인가}
  F -->|아니오| G[잠김 안내 Toast]
  F -->|예| C
  C --> H[구절 선택]
  H --> I{One Verse 선택됨}
  I -->|아니오| J[완료 시 One Verse 선택 안내]
  J --> H
  I -->|예| K[읽기 완료 확인]
  K -->|확인| L[완료 성공 Modal]
  K -->|취소| C
```

## Journey 02 — One Verse와 Mark 관리

**목표:** 오늘 남길 한 구절을 정하고, 별도 후보 구절을 Mark한다.  
**진입점:** 말씀 뷰어의 본문 구절.  
**완료 조건:** One Verse 초안 또는 Mark 후보 저장 성공.

```mermaid
flowchart TD
  A[미완료 Day의 구절] --> B[구절 선택]
  B --> C{사용자 액션}
  C -->|One Verse| D[One Verse 지정/교체 확인]
  D -->|확인| E[One Verse 초안 저장]
  C -->|Mark| F{이미 Mark됨}
  F -->|아니오| G[Mark 후보 저장]
  F -->|예| H[Mark 후보 제거]
  E --> I[선택 UI 갱신]
  G --> I
  H --> I
  E -->|실패| J[실패 Toast]
  G -->|실패| J
  H -->|실패| J
```

## Journey 03 — 마음새김

**목표:** One Verse를 음성 또는 쓰기로 훈련한다.  
**진입점:** 읽기 완료 구절, 마이페이지/날짜 상세의 마음새김 행동.  
**완료 조건:** 훈련 성공 후 완료 처리.

```mermaid
flowchart TD
  A[마음새김 Modal] --> B[훈련 준비]
  B --> C{도전 방식}
  C -->|음성| D[녹음/음성 인식]
  C -->|쓰기| E[쓰기 답안 입력]
  D --> F{판정}
  E --> G{판정}
  F -->|성공| H[성공 결과]
  G -->|성공| H
  F -->|실패| D
  G -->|실패| E
  H --> I[마음새김 완료 저장]
```

## Journey 04 — 친구와 발자국

**목표:** 친구를 찾거나 친구의 말씀 기록을 보고 좋아요를 남긴다.  
**진입점:** 친구 탭, 친구 요청 badge.  
**완료 조건:** 요청 전송/응답 또는 좋아요 처리.

```mermaid
flowchart TD
  A[친구 탭] --> B{탭 선택}
  B -->|내 친구| C[친구 목록과 최신 발자국]
  B -->|받은 요청| D[수락 또는 거절]
  B -->|친구 찾기| E[닉네임 검색]
  E --> F{검색 결과}
  F -->|없음| G[빈 결과]
  F -->|있음| H[친구 요청 전송]
  C --> I[친구 상세]
  I --> J[발자국 좋아요]
```

## Journey 05 — 개인 기록 회고와 발자국 작성

**목표:** 과거 One Verse를 찾고 발자국을 작성·공유·훈련한다.  
**진입점:** 마이페이지 달력/월간 목록, 읽기 화면.  
**완료 조건:** 발자국 저장 또는 공유 요청 실행.

```mermaid
flowchart TD
  A[마이페이지] --> B[달력 또는 월간 기록 선택]
  B --> C[날짜별 One Verse 상세]
  C --> D{행동}
  D -->|발자국| E[발자국 편집]
  E --> F[항목 저장]
  D -->|공유| G[공유 Modal]
  D -->|마음새김| H[마음새김 Modal]
```
