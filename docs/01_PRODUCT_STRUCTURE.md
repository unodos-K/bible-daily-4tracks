# One Verse Product Structure

## Information Architecture

```text
One Verse
├─ 앱 진입·계정
│  ├─ 시작 화면 (/)
│  ├─ Kakao 로그인 및 인증 콜백
│  └─ 닉네임 설정 온보딩
├─ 홈 (/home)
│  ├─ 오늘의 읽기 진도·다음 Day
│  ├─ 읽기 진행률·마음새김 요약
│  ├─ 일정 미리보기/일정 Bottom Sheet
│  └─ 말씀 뷰어 진입
├─ 말씀 뷰어 (/read)
│  ├─ Day 이동·Day 선택 시트
│  ├─ 구약 / 신약 / 시편 / 잠언 읽기
│  ├─ 구절 선택
│  ├─ One Verse 지정·재선택
│  ├─ Mark 추가·해제 및 Mark 이동
│  ├─ 읽기 완료·완료 취소
│  ├─ 공유
│  └─ 마음새김 진입
├─ 마음새김 (읽기/기록 화면의 Modal)
│  ├─ 음성 듣기·음성 도전
│  ├─ 쓰기 도전
│  └─ 성공/실패 결과
├─ 발자국 (/memo)
│  ├─ 항목 선택
│  ├─ 묵상·기도·감사·삶의 적용 작성/수정
│  └─ 저장
├─ 친구 (/friends, /friend/[id])
│  ├─ 친구 목록·친구 발자국
│  ├─ 친구 요청 수신/응답
│  ├─ 닉네임 검색·친구 요청
│  └─ 좋아요
├─ 마이페이지 (/mypage)
│  ├─ 월간 달력·날짜별 기록
│  ├─ 월간 One Verse/통독/마음새김 요약
│  ├─ 발자국/공유/마음새김 진입
│  └─ 날짜별 One Verse 상세 (/verse/[date])
└─ 설정 (/settings)
   └─ 읽기 관련 설정
```

## 최상위 영역

| 영역 | 목적 | 핵심 행동 | 주요 진입/연결 |
|---|---|---|---|
| 홈 | 오늘의 읽기 맥락 제공 | 일정 확인, 읽기 시작 | 하단 홈, 말씀 뷰어 |
| 말씀 뷰어 | 매일 4트랙 읽기와 구절 선택 | Day 이동, One Verse/Mark, 완료 | 홈, 하단 탭, 마음새김/발자국 |
| 마음새김 | 선택한 말씀을 반복 훈련 | 음성·쓰기 도전 | 읽기/기록의 One Verse |
| 친구 | 관계 기반 기록 탐색 | 검색, 요청, 좋아요 | 하단 친구, 친구 상세 |
| 마이페이지 | 개인 기록 회고 | 달력 탐색, 기록·공유·훈련 | 하단 마이페이지, 날짜 상세 |

하단 네비게이션은 홈·말씀 뷰어·친구·마이페이지를 연결한다. 발자국, 설정, 날짜 상세는 해당 기능에서 진입하는 보조 화면이며 하단 탭을 숨긴다.
