# One Verse 재선택

## 최종 정책

2026-09-21 추가 확인에 따라 **최초 최종 선택 저장은 해당 Day 자동 완료**를 유지한다.
별도 읽기 완료 버튼은 복구하지 않는다. 구절 클릭·Mark·확인창 열기는 저장하지 않는다.
완료한 Day에서도 다른 구절을 클릭해 변경하거나 `다시 선택하기`로 선택만 취소할 수 있다.
선택 취소는 완료 취소가 아니다. 기존 완료 시각·읽은 날짜는 유지한다.
완료 후 Mark 추가/해제 제한은 기존 정책 그대로이며, 저장된 Mark는 유지한다.

## 저장 및 보존

- `set_one_verse_selection`은 `auth.uid()` 소유 기록만 처리한다.
- 신규 기록은 한국 날짜로 생성하고 선택 저장과 최초 완료를 같은 트랜잭션에서 처리한다.
- 기존 미완료 기록에 최종 구절을 저장하면 최초 완료 시각을 추가한다. 과거 미완료 기록의 일괄 보정은 하지 않는다.
- 완료 기록은 `completed_at`·`read_date`를 유지한다. 선택 취소 시 `one_verse`만 NULL로 변경한다.
- 행 잠금 및 전체 JSON 비교로 다른 탭에서 바뀐 선택/발자국을 덮어쓰지 않는다. 동일 값 재시도는 중복 이력을 만들지 않는다.
- 기존 `one_verse` JSON 전체를 `one_verse_selection_history`에 보관한다. 일반 사용자에게는 본인 이력 조회만 허용한다. 추가·수정·삭제 권한은 부여하지 않는다.
- 기존 발자국·마음새김은 새 구절에 붙이지 않는다. 현재 UI에 이력 열람/복원 기능은 없으며 확인창에서 이를 고지한다. 같은 구절 재선택도 자동 복원하지 않는다.
- 아멘은 기존 `(liker_id,author_id,day_index)` 구조를 유지한다. 구절 교체 후에도 Day에 남는다는 점을 확인창에 설명한다.
- 다른 Day·후보 Mark·아멘·친구·기존 알림은 변경하지 않는다.
- 첫 완료의 기존 알림은 발생하지만, 완료된 Day 재선택/취소는 읽기 알림 트리거를 호출하지 않는다. 연속 읽기 알림 비활성 정책과 관리자 보정 가드는 유지한다.
- 구버전 최초 저장 RPC는 유지한다. 새로운 변경/취소 흐름은 별도 RPC를 사용한다.

## 적용

새 마이그레이션: `20260921100000_separate_one_verse_selection.sql`.
이름의 separation은 재선택과 완료 취소의 분리를 뜻하며, 최초 선택 자동 완료를 해제하지 않는다.
이력 테이블·소유자 조회 정책·선택 RPC를 추가하고 기존 읽기 알림 트리거에 재선택 제외 조건을 추가한다.
기존 데이터를 일괄 수정/삭제하지 않는다. 운영 DB에는 이번 작업에서 적용하지 않았다.
배포 전에 원격 마이그레이션 이력 및 선행 관리자 마이그레이션 적용 여부를 확인하고 승인된 대상만 적용해야 한다.
새 RPC 적용 전 코드를 배포하면 선택 저장이 실패하므로 DB 적용을 먼저 진행한다.

## 검증 구분

- `npm run test:one-verse-selection`: 로컬 PGlite 실제 SQL 실행. 자동 완료, 변경/취소, 날짜 보존, CAS 충돌, 중복 요청, 비로그인 거부, 소유권, 이력 RLS, 실패 롤백, 기존 Mark/아멘/알림 보존.
- 기존 `test:notifications`, `test:admin`, `test:admin-records`: 기존 마이그레이션 기준 회귀 테스트. 새 정책 SQL 통합 검증은 위 테스트가 담당한다.
- `scripts/test-one-verse-selection-browser.cjs`: 실제 hook/행/액션/확인창을 Chrome에서 실행하되 저장·인증은 합성 fixture로 대체한다. 운영 로그인 검증이 아니다.
- 브라우저 도구는 별도 임시 경로에 `playwright esbuild`를 설치하고 `ONE_VERSE_BROWSER_TOOLS`로 지정한다. 빌드된 CSS 경로를 `ONE_VERSE_TEST_CSS`로 전달하면 실제 앱 스타일로 검증한다.
- 실제 iOS/Android PWA, 운영 사용자 세션, 원격 DB 적용 및 재접속 영속성은 별도 확인이 필요하다.
- Chrome의 320·390·768·1280px에서 확인 전 미저장, 자동 완료, 완료 후 구절 변경/취소, 실패 후 재시도, 빠른 중복 클릭 차단, Mark 유지, Escape, 확인창 화면 경계를 검증했다. 실제 모바일 기기 검증은 아니다.
